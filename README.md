# Nicesuno

一款基于[Suno](https://suno.com/)和[中转Suno-API]创作音乐的chatgpt-on-wechat插件。

+ 使用方法：
```
1.创作声乐
用法：唱/演唱<提示词>
示例：唱明天会更好。

2.创作器乐
用法：演奏<提示词>
示例：演奏明天会更好。

3.创作歌词
用法：写歌/作词<提示词>
示例：写歌明天会更好。

4.自定义模式
用法：
唱/演唱/演奏
标题: <标题>
风格: <风格1> <风格2> ...
<歌词>
备注：前三行必须为创作前缀、标题、风格，<标题><风格><歌词>三个值可以为空，但<风格><歌词>不可同时为空！
```
