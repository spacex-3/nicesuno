# Nicesuno

一款基于[Suno](https://suno.com/)和[中转Suno-API]创作音乐的chatgpt-on-wechat插件。

+ 使用方法：
```
1.创作声乐
用法：唱/演唱<提示词>
示例：唱明天会更好。

2.创作器乐
用法：演奏<提示词>
示例：演奏明天会更好。

3.自定义模式
用法：
唱/演唱/演奏
标题: <标题>
风格: <风格1> <风格2> ...
<歌词>
备注：前三行必须为创作前缀、标题、风格，<标题><风格><歌词>三个值可以为空，但<风格><歌词>不可同时为空！
```

+ 使用逻辑：
```
1、先输入$suno_admin_password 密码（暂定12345678）设定当前发送消息的帐号为管理员。
2、管理员输入$suno_help，可以获取使用说明和管理员指令；非管理员输入$suno_help，仅可以获取使用说明。
3、限制次数针对的是个人，比如一个群里面两个人，他们每天的次数都分别是多少次，不是针对群聊可以使用多少次。
4、权限分为：
4.1 普通用户（限制次数，次数为0无法使用，会有提示）
4.2 白名单用户（次数为0也可以继续使用）
4.3 黑名单用户（无法使用，会直接调用大模型）
4.4 白名单群组（普通用户次数为0但是在白名单群组里面也可以继续用；黑名单用户不可用，会直接调用大模型）
4.5 黑名单群组（除了管理员所有人都不可以用，会直接调用大模型）
